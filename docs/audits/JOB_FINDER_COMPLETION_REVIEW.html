Non-negotiable boundary

No application was submitted.

  • Every live flow used an isolated temporary workspace and synthetic candidate data.
  • Final-submit and account-creation authorization remained false.
  • The final controls were identified and intentionally left untouched.
  • Login, CAPTCHA, MFA, legal consent, missing answers, and uploads become exact resumable user actions.
  • Opening a browser never counts as authentication; the user must confirm and the app must verify the exact checkpoint.
Honest remaining limits

What this review does not claim.

Computer Use helper unavailable

The signed helper repeatedly failed to start with spawn EPERM. After exhausting the bounded retry, current visual evidence was captured from the real production Electron app by the root-owned Playwright harness. There were no competing app sessions or subagent GUI worktrees.

External states remain external

Authenticated Workday continuation was not tested because no voluntary sign-in was supplied. macOS/Linux Interview Helper capture and audio behavior require those target hosts.

No real résumé sent to an external model

Configured-provider comparisons used synthetic fixtures. This proves the integration and safety contract, not how a specific private résumé will read without human review.

Final submit is intentionally absent

The product is proven through the safe checkpoint only. A future explicit opt-in submission feature would require a separate authorization design and acceptance pass.

Recommended user review

Review the product in this order.

  1. Import a résumé and inspect role/date/bullet association plus the direct review links for uncertain fields.
  2. Run discovery and judge the first useful results, fit reasons, source progress, and changed-result explanations.
  3. Shortlist one job; compare Original CV with Tailor for this job; export and approve the chosen asset.
  4. Confirm the single Prepare application action is obvious without reading the claim-trust details.
  5. Let the agent reach a sign-in or final-review boundary; use Needs you only if you voluntarily complete the browser action.
  6. Stop before the final site button. Report any confusing copy, bad résumé claim, wrong fit, or layout issue with a screenshot.
